隐私政策

生效日期：2026 年 11 月 8 日　｜　适用版本：1.0.0 及以上　｜　开发者：TapeOut 社区 · 昆哥
一句话总结： TapePost 是一个纯本地的浏览器扩展。它没有服务器、没有账号体系、没有统计或遥测，不会把你看到的网页内容、图片、文字或任何个人数据上传到开发者或第三方服务器。所有提取、去水印、剪贴板写入和文件下载都发生在你的浏览器和本机。

1. 我们会处理哪些数据

仅在你主动点击页面上的「一键转发」按钮时，扩展才会在当前标签页读取下列内容，并且只在本机处理：

  • 当前这条内容的正文文字（用于清洗后预填到 X 发推框）；
  • 这条内容的配图与视频直链地址（用于下载到本地、写入剪贴板或在本地做去水印）；
  • 这条内容的固定链接与标识（用于可选的原推链接标注、文件命名）；
  • 页面 DOM 结构（用于定位正文、内容图与插入转发按钮）。

扩展不会读取与你正在转发的内容无关的标签页，不会读取密码、Cookie、表单输入或浏览历史。

2. 数据存到哪里

  • 设置项（去水印开关、站点开关、署名开关等）保存在浏览器的 chrome.storage.local，仅存于本机；若你开启了 Chrome 同步，浏览器可能按你自己的 Chrome 设置同步这部分偏好。
  • 处理后的图片写入系统剪贴板，或按你的操作下载到本机下载目录；文件名前缀为 xpost_。
  • 文字只通过 URL 参数预填到 x.com/intent/tweet 或 twitter.com/intent/tweet 的新标签页，由你手动点击发送。扩展不调用任何发布接口，也不会替你发帖。

我们（开发者）不运营任何后端服务，因此无法访问、收集、存储或分析上述数据。

3. 网络请求

扩展会向内容所在的图片/视频 CDN 发起请求以下载媒体（例如 sinaimg.cn、zhimg.com、qpic.cn、hdslb.com、doubanio.com、xhscdn.com、twimg.com）。为通过图床防盗链校验，扩展会用 declarativeNetRequest 为这些请求设置对应站点的 Referer 请求头。微博视频会优先查询公开的 m.weibo.cn/statuses/show 接口获取高清地址（请求中仅包含该条内容的公开 ID）。除此之外没有其它外发请求，没有分析、广告或跟踪代码，也没有远程加载的脚本。

4. 权限说明

权限用途
storage在本机保存你的设置偏好
clipboardWrite把你点选的干净图片写入系统剪贴板，便于在 X 里粘贴
downloads把处理后的图片/视频保存到本机下载目录
offscreen创建离屏文档，在后台用 Canvas 处理图片并写入剪贴板
declarativeNetRequest为图片 CDN 请求设置 Referer，避免防盗链导致下载失败
站点主机权限仅在你打开的 7 个已启用站点页面上识别内容、注入按钮并读取配图

你可以在扩展设置面板里逐个关闭站点；关闭某个站点后，扩展不会在该站点注入任何界面。

5. 第三方内容与你的责任

扩展帮助你搬运公开页面的文字与图片。这些内容的权利属于原作者，转载、二创或转发前请自行确认授权，并建议开启设置里的「附原推链接」标注来源。X（x.com / twitter.com）的服务与可达性由 X 自行负责，本扩展与其无关联，也不代表其官方。

6. 儿童隐私

本扩展不面向 13 岁以下儿童，也不会有意收集任何年龄信息。

7. 变更与联系

如政策有实质变更，我们会更新本页并同步提升扩展版本号。如需咨询或反馈，请通过 Chrome 网上应用店该扩展页面的「支持 / 开发者联系方式」渠道联系开发者。

T TapePost · 一键转发到 X

隐私政策

生效日期：2026 年 11 月 8 日　｜　适用版本：1.1.0 及以上　｜　开发者：TapeOut 社区 · 昆哥
一句话总结： 扩展本身没有服务器、没有账号体系、没有统计或遥测。「一键转发」的提取、去水印、剪贴板与下载全部在本机完成，不上传任何数据。只有当你主动使用 AI 功能（X 上的「AI 评论」或生态面板的「链接真伪查询」）时，扩展才会把你点选的那段文字或那条链接，连同你设定的提示词，用你自己的 API Key 发送给 xAI 的 Grok 接口；不使用时不会发出这类请求。

1. 我们会处理哪些数据

仅在你主动点击页面上的「一键转发」「AI 评论」或生态面板的「核验链接」时，扩展才读取下列内容：

  • 当前这条内容的正文文字（转发时用于清洗后预填到 X 发推框；AI 评论时用于生成回复候选，截断至最多 1200 字符）；
  • 这条内容的配图与视频直链地址（仅用于下载到本地、写入剪贴板或在本地做去水印）；
  • 这条内容的固定链接与公开标识（用于可选的原推链接标注、回复目标定位、文件命名）；
  • 你在生态面板输入框里粘贴的待核验链接；
  • 页面 DOM 结构（用于定位正文、内容图与插入按钮）。

扩展不会读取与你正在操作的内容无关的标签页，不会读取密码、Cookie、表单输入或浏览历史，也不会上传图片或视频文件。

2. 数据存到哪里

  • 偏好设置（去水印开关、站点开关、署名开关、提示词等）保存在 chrome.storage.sync；若你开启了 Chrome 同步，浏览器会按你自己的同步设置同步这部分偏好。
  • xAI API Key 与接口配置（模型、协议、网关地址）保存在 chrome.storage.local，仅存本机、不同步、不随扩展分发，只用于向你指定的接口发起带 Authorization 头的请求。开发者无法读取它。
  • 处理后的图片写入系统剪贴板，或按你的操作下载到本机下载目录；文件名前缀为 xpost_。
  • 文字只通过 URL 参数预填到 x.com/intent/tweet 或 twitter.com/intent/tweet 的新标签页，由你手动点击发送。扩展不调用任何发布接口，也不会替你发帖或回复。
  • 官方平台清单是内置在扩展代码里的静态数据（来源 TapeOut.link 的 OFFICIAL 标记，核验日期 2026-11-08），不会联网拉取，也不包含你的任何信息。

我们（开发者）不运营任何后端服务，因此无法访问、收集、存储或分析上述数据。

3. 网络请求

转发链路：扩展会向内容所在的图片/视频 CDN 发起请求以下载媒体（例如 sinaimg.cn、zhimg.com、qpic.cn、hdslb.com、doubanio.com、xhscdn.com、twimg.com）。为通过图床防盗链校验，扩展会用 declarativeNetRequest 为这些请求设置对应站点的 Referer 请求头。微博视频会优先查询公开的 m.weibo.cn/statuses/show 接口获取高清地址（请求中仅包含该条内容的公开 ID）。

AI 链路（仅主动使用时）：见下节。

扩展没有分析、广告或跟踪代码，没有远程加载的脚本，也不连接开发者自建的服务器。

4. AI 功能与第三方服务（xAI Grok）

1.1.0 起新增两个由你手动触发的 AI 功能。它们共用同一个后台请求通道，不填 API Key 就不会发出任何 AI 请求：

  • X 一键评论：点击后把该条推文的正文 + 你设定的评论提示词发送给 https://api.x.ai/v1（或你在设置里填写的兼容网关），由 Grok 生成 3 条回复候选。候选只显示在本机浮层里；选中后才预填到 X 回复框，发送由你手动完成。
  • 链接真伪查询：点击核验后把待核验链接 + 内置官方清单 + 你设定的核验提示词发送给同一接口，由 Grok 生成解释与仿冒风险判断。最终是否给「官方绿标」由本地白名单决定，不采信模型结论。

不会发送：浏览历史、Cookie、X 登录态、其它标签页内容、图片/视频文件、你的账号密码，以及除 API Key 之外的任何凭据。

第三方责任：发送给 xAI 的内容受 xAI 的隐私政策与其服务条款约束，xAI 可能会按其政策临时处理请求内容；调用额度与费用由你自行承担。如果你填写的是第三方兼容网关，该网关的运营方同样会收到上述内容，请先确认你信任它。扩展开发者不接收、不留存这些内容。

你可以在设置面板里删除 API Key 或关闭「AI 评论」按钮；删除后 AI 功能立即停用，转发功能仍然完全离线可用。

5. 权限说明

权限用途
storage在本机保存设置偏好与你的 API Key
clipboardWrite把你点选的干净图片或评论文字写入系统剪贴板，便于在 X 里粘贴
downloads把处理后的图片/视频保存到本机下载目录
offscreen创建离屏文档，在后台用 Canvas 处理图片并写入剪贴板
declarativeNetRequest为图片 CDN 请求设置 Referer，避免防盗链导致下载失败；固定 9 条规则，不拦截其它流量
站点主机权限仅在你打开的 7 个已启用站点页面上识别内容、注入按钮并读取配图
api.x.ai 主机权限仅在你主动使用 AI 功能时，向 xAI 官方接口发送生成请求
可选主机权限（默认未授予）仅当你在设置里填写自定义网关并主动点「允许网关域名」时，才申请该域名的访问权

你可以在扩展设置面板里逐个关闭站点；关闭某个站点后，扩展不会在该站点注入任何界面。

6. 第三方内容与你的责任

扩展帮助你搬运公开页面的文字与图片、生成回复草稿、核验链接。原内容的权利属于原作者，转载、二创或转发前请自行确认授权，并建议开启设置里的「附原推链接」标注来源。Grok 生成的评论与核验结论仅供参考，请自行判断后再发布或访问；链上平台务必再次核对地址、谨慎授权钱包。X（x.com / twitter.com）与 xAI 的服务与可达性由其自行负责，本扩展与其无关联，也不代表其官方。生态面板的「官方认定」清单来自公开的 TapeOut.link 标记，不构成任何背书或投资建议。

7. 儿童隐私

本扩展不面向 13 岁以下儿童，也不会有意收集任何年龄信息。

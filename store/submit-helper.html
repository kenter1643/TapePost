✅ 已解决：两步验证（2FA）

  1. 打开 myaccount.google.com 两步验证 →「开始使用」→ 验证密码。推荐用 Authenticator 验证器 / 通行密钥；+86 手机号短信有时收不到，务必保存 10 个备用码。
  2. 确认页面显示「已开启」后，退出 Chrome Web Store Developer Dashboard 并重新登录一次（旧会话不带 2FA 状态，只刷新页面通常不够），必要时等几分钟。
  3. 回到 Dashboard 重新上传同一个 zip，不需要重新打包。若仍报同样错：检查 Chrome 是否登录了多个 Google 账号，用无痕窗口只登录开发者账号再试。

官方政策：所有开发者账号在发布新扩展或更新现有扩展前必须启用 2-Step Verification。
